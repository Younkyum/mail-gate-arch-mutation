문의는 [support@atmark.ai](mailto:support@atmark.ai)로 보내 주세요.

## 함께 적으면 좋은 것

- 조직 이름과 소유자 주소
- 관련 에이전트의 주소나 에이전트 ID
- 문제가 생긴 시각
- 화면이나 API에 나온 오류 코드(`recipient_not_allowlisted`, `401` 등)

:::warning 토큰은 보내지 마세요
에이전트 토큰, 조직 API 키, 웹훅 시크릿은 문의 메일에 넣지 않습니다. 지원팀은 이 값을 묻지 않습니다. 이미 보냈다면 바로 교체하세요.
:::

## 지원팀에 요청해야 하는 일

- 조직이나 계정 삭제
- 조직 이름·소유자 주소 변경
- 가입 거절이나 운영자 동결 문의
- 결제가 열리지 않을 때 요금제 변경

문서에서 틀린 곳을 찾으면 같은 주소로 알려 주세요.
