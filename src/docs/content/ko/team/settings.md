왼쪽 메뉴의 **설정**을 누르면 설정 메뉴가 열리고, 고른 항목 하나만 오른쪽에 보입니다. 화면이 좁으면 설정 메뉴가 위쪽 가로 탭이 됩니다.

| 묶음 | 항목 | 하는 일 |
|---|---|---|
| 조직 | 일반 | 조직 이름, id, 소유자, 검토 상태, 내 역할 |
| | 멤버와 초대 | 멤버, 역할, 초대. [멤버와 역할](/team/members-and-roles) |
| | API 키 | 조직 API 키. [조직 API 키](/team/org-api-keys) |
| | 요금제 | 요금제와 사용량, 업그레이드. [요금제 바꾸기](/plans/change-plan) |
| 운영 | 긴급 정지 | 조직 전체 발신 멈추기. [긴급 정지](/email/emergency-stop#org) |
| 개인 | 화면 | 테마(시스템·라이트·다크)와 언어. 이 브라우저에 저장됩니다. |
| | 메일 | 시스템 메일 언어(English · 한국어). 로그인 코드 · 승인 요청 · 알림 메일을 이 언어로 받습니다. |
| | 세션 | 로그인한 주소, 로그아웃 |

## 일반

조직 이름과 소유자 주소는 가입 때 정해지고 콘솔에서 바꿀 수 없습니다. 바꿔야 한다면 [지원팀](/help/contact)에 요청하세요.

## 세션 {#session}

- 로그인은 이메일로 받은 6자리 코드로 합니다. 로그인을 요청한 브라우저에서만 되고, 15분 동안 한 번 쓸 수 있습니다. 메일을 휴대폰에서 읽었다면 코드를 옮겨 적으세요.
- 세션은 12시간 유지됩니다.
- **모든 기기에서 로그아웃**은 내 콘솔 세션을 전부 끊습니다. 모든 조직, 다른 브라우저와 기기, 지금 브라우저까지 포함합니다. 세션이 샜다고 의심될 때 씁니다.

## 계정 삭제

콘솔에서는 계정이나 조직을 지울 수 없습니다. [지원팀](/help/contact)에 요청하세요.
