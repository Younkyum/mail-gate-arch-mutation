## 시작하기 전에

- 역할이 소유자나 관리자여야 합니다.
- 요금제의 에이전트 한도까지 만들 수 있습니다. Free는 3개입니다. (예전에 가입해 아직 운영자 검토 중인 조직은 2개까지입니다.)

:::steps
### 새 에이전트 창 열기
콘솔의 **에이전트**에서 **에이전트 추가**를 누릅니다.

### 이름과 주소 적기
**이름**은 콘솔에서 알아볼 이름입니다. **주소**에는 `@` 앞부분만 적습니다. 예: `founder`를 적으면 `founder@atmark.ai`가 됩니다.

### 만들기
**추가**를 누릅니다. 토큰 창이 열리면 토큰을 복사해 안전한 곳에 저장한 뒤 닫습니다. 토큰은 이 창에서만 보입니다. 연결은 클라이언트마다 다릅니다. [에이전트 연결 방법 고르기](/connect/overview)를 보세요.
:::

:::feature customDomains
회사 도메인을 연결했다면 창에 **주소 도메인**이 생깁니다. `@atmark.ai`(기본)나 확인이 끝난 내 도메인을 고릅니다. 내 도메인을 고르면 그 주소가 대표 주소가 되고, 이 에이전트는 `@atmark.ai` 주소를 보이지도 쓰지도 않습니다. [내 도메인으로 메일 주고받기](/email/custom-domains#addresses)
:::

## 주소 규칙 {#address-rules}

- 영문 소문자, 숫자, `.` `_` `-`만 씁니다.
- 처음과 끝은 영문이나 숫자여야 합니다.
- 1~64자. 점(`.`)을 두 번 잇달아 쓸 수 없습니다.
- 예약된 주소와 이미 쓰는 주소는 고를 수 없습니다.
- **만든 뒤에는 바꿀 수 없습니다.**

## 함께 생기는 것

| 항목 | 처음 상태 |
|---|---|
| 대표 주소 | 바로 메일을 받습니다. |
| 발신 정책 | **전체**(2026년 10월 13일부터). 누구에게나 보낼 수 있고, 한도와 위험 보류는 그대로입니다. 보낼 상대가 정해지면 [허용 목록](/email/sending)으로 좁힙니다. |
| 수신 정책 | **전체**. 누구의 메일이든 보입니다. |
| 신원 | 게시 전. 원하면 [게시](/identity/publish)합니다. |
| 토큰 | **정책 변경 요청**을 포함한 기본 권한의 토큰 하나 |

## 에이전트 수 세는 법 {#counting}

한도마다 세는 에이전트가 다릅니다.

| 한도 | 긴급 정지한 에이전트 | 삭제한 에이전트 |
|---|---|---|
| 검토 중 상한(2개, 예전 가입으로 아직 검토 중인 조직만) | 셈 | 셈 |
| 요금제의 에이전트 한도 | 셈 | 세지 않음 |
| 삭제한 것 포함 총합(요금제 한도의 3배) | 셈 | 셈 |

삭제는 개요 맨 아래 **에이전트 삭제**로 하고, 되돌릴 수 없습니다. [에이전트 삭제](/agents/disable-delete#delete) 총합에 계속 세는 것은 삭제와 다시 만들기를 되풀이해 주소를 끝없이 가져가지 못하게 하기 위해서입니다. 요금제별 한도는 [요금제와 한도](/plans/plans-and-limits)에 있습니다.
