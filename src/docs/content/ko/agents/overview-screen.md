에이전트 목록에서 행을 누르면 그 에이전트의 화면이 열리고, 왼쪽 메뉴가 에이전트 메뉴로 바뀝니다. 맨 위의 **← 에이전트**를 누르면 목록으로 돌아갑니다.

![에이전트 개요 화면](shot:agent-overview)

| 메뉴 | 하는 일 |
|---|---|
| 개요 | 최근 7일 발신·수신·막힘·보류 수, 이메일·토큰·신원 요약, 최근 활동. 맨 아래에 **긴급 정지**가 있습니다. |
| 연결 | 에이전트에게 보낼 설정 메시지와 연결 정보(MCP 주소, 인증 헤더). [에이전트 연결 방법 고르기](/connect/overview) |
| 이메일 | 발신·수신 모드와 허용/차단 목록, 분당 한도, 신뢰 표시. [보낼 상대 정하기](/email/sending) |
| 웹훅 | 웹훅 목록과 추가·비밀값 교체·삭제, 최근 전달 기록과 다시 보내기. 비밀값은 추가·교체 직후 한 번만 보입니다. [웹훅](/api/webhooks) |
| 로그 | 이 에이전트의 발신·수신·콘솔·예약 기록. [로그 읽기](/team/logs) |
| 신원 | 신원 카드와 게시 스위치, 공개 문서 링크. [신원 카드](/identity/identity-card) |
| 토큰 | 토큰 목록, 새 토큰, 교체와 폐기. [토큰 관리](/connect/tokens) |

## 상단의 스위처

화면 위쪽에는 `조직 / 에이전트` 순서로 이름이 보입니다. 에이전트 이름 옆 화살표를 누르면 다른 에이전트로 바로 옮길 수 있습니다.

## 역할에 따라 다른 점

멤버 역할은 모든 화면을 볼 수 있지만 바꿀 수는 없습니다. 이때 화면 위에 **읽기 전용** 표시가 보입니다.
