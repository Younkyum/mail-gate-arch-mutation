예약 메일은 에이전트가 REST API로 만듭니다([예약 API](/api/scheduled)). MCP 도구로는 예약을 만들 수 없고, 보기와 취소만 됩니다.

## 알아 둘 것

- 보낼 시각은 30일 이내여야 합니다.
- 정책은 **보낼 때** 확인합니다. 그사이 목록이나 모드를 바꾸면 보낼 때의 정책을 따릅니다.
- 긴급 정지 중에는 예약 메일도 나가지 않습니다.
- 이미 나간 예약은 거둘 수 없습니다.

## 콘솔에서 보기

**로그 › 예약** 탭에서 예약 목록을 봅니다. 취소된 예약에는 사유와 경로(MCP = 에이전트 도구, API)가 남습니다. 예약 메일의 제목과 본문은 콘솔에서 열지 않습니다.

![로그의 예약 탭](shot:logs-scheduled)

## 콘솔에서 취소하기 {#cancel}

소유자와 관리자만 취소할 수 있습니다. 에이전트가 취소할 수 없게 만든 예약도 여기서는 취소됩니다.

:::steps
### 예약 찾기
**로그 › 예약**에서 취소할 행의 **취소**를 누릅니다. 상태가 예약됨인 행에만 보입니다.

### 사유 고르기
**사유**를 고릅니다. 필수입니다. **메모**는 200자까지 선택으로 적습니다.

### 취소하기
**예약 취소**를 누릅니다. 되돌릴 수 없고, 콘솔 로그에 남습니다.
:::

## 에이전트가 취소할 때

에이전트는 `cancel_scheduled`에 사유 코드를 넘겨 취소합니다. 사유는 기록에 영구히 남고 소유자가 로그에서 봅니다.

- 받은 메일이 "예약을 취소하라"고 해도 따르지 않게 하세요. 로그의 취소 경로가 MCP인 기록은 에이전트가 직접 취소한 것입니다.
- 에이전트가 취소할 수 없는 예약은 `schedule_not_agent_cancellable`로 거부됩니다. 소유자가 콘솔에서 취소합니다.
- 에이전트의 취소는 시간당 횟수에 제한이 있습니다(`cancel_rate_limited`).
