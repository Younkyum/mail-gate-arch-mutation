## 시작하기 전에

- 모드와 목록을 바꾸려면 역할이 소유자나 관리자여야 합니다.

## 수신 모드 {#modes}

| 모드 | 동작 |
|---|---|
| 전체 | 모든 발신자의 메일이 에이전트에게 보입니다. **새 에이전트의 기본값**입니다. |
| 허용 목록 | 허용 목록에 있는 발신자의 메일만 보입니다. 나머지는 보류됩니다. |
| 차단 목록 | 차단 목록에 있는 발신자의 메일만 보류하고 나머지는 보입니다. |
| 모두 막기 | 모든 메일을 보류합니다. 에이전트 수신함이 비어 있습니다. |

바꾸는 방법은 발신과 같습니다. **이메일** 화면의 **수신** 열에서 모드를 고르고 **저장**을 누릅니다. 에이전트가 수신 모드나 목록의 변경을 [요청](/email/allow-block-lists#requests)할 수도 있습니다. 승인하기 전에는 아무것도 바뀌지 않습니다.

:::warning 허용 목록으로 바꾸기 전에
먼저 받을 발신자를 수신 허용 목록에 넣습니다. 바꾼 뒤 목록에 없는 발신자의 메일은 보류되고, 수신 정책으로 보류된 메일은 나중에 풀 수 없습니다. [허용/차단 목록 고치기](/email/allow-block-lists)
:::

:::warning "모두 막기"를 고르기 전에
인증 코드와 회신도 보류됩니다. 에이전트를 멈추려는 것이라면 [긴급 정지](/email/emergency-stop)를 쓰세요.
:::

## 보류 {#quarantine}

- 막힌 메일은 보낸 사람에게 반송하지 않고 보류합니다.
- 보류된 메일은 에이전트에게 보이지 않습니다. 에이전트는 수신함 목록에서 보류된 메일의 **개수**만 봅니다.
- 소유자는 로그의 **수신** 탭에서 보류된 메일의 기록과 사유를 봅니다. 본문은 콘솔에서도 열지 않습니다.
- 수신 정책으로 보류된 메일은 풀어서 에이전트에게 넘길 수 없습니다(인젝션 위험 · 검사로 보류된 메일은 [감시](/security/watch)에서 다룹니다). 목록을 고친 뒤 보낸 쪽에 다시 보내 달라고 합니다.
- 보류 사유는 로그 상세에 넷 중 하나로 보입니다.

| 사유 | 뜻 | 할 일 |
|---|---|---|
| 수신 정책으로 보류 | 수신 모드나 목록이 막았습니다. | 목록을 고친 뒤 다시 보내 달라고 합니다. |
| 인젝션 위험으로 보류 | 에이전트를 속이려는 지시가 든 것으로 보였습니다. 수신 모드와는 상관없습니다. | 정상 메일이라면 다른 경로로 내용을 받습니다. 예: 사람 담당자에게 보내 달라고 합니다. |
| 검사 실패로 보류 | 메일 검사를 마치지 못했습니다. 수신 모드와는 상관없습니다. | 잠시 뒤 다시 보내 달라고 합니다. |
| 위험 등급으로 보류 | 위험 등급 메일이고, 에이전트별 설정이 보류입니다. 수신 모드와는 상관없습니다. | [감시 › 보류된 메일](/security/watch#release)에서 확인하고 풀어 줄 수 있습니다. |

## 허용 목록은 발신 도메인 인증까지 봅니다 {#dmarc}

수신 허용 목록은 발신 도메인 인증(DMARC)을 통과한 메일만 맞춰 봅니다. 주소로 규칙을 넣어도 확인되는 것은 그 도메인이 DMARC를 통과했다는 것까지입니다. 그 도메인 안의 특정 메일함이 보냈다는 증명은 아닙니다.

## 신뢰 표시 {#trust}

받은 메일의 발신자를 `seen`으로 표시해 두면 에이전트가 수신 목록에서 `sender_trust: "seen"`을 봅니다. 표시하지 않은 발신자는 `unknown`입니다. 신뢰도는 자동으로 오르지 않습니다. 수신 모드와는 상관없습니다.

1. **이메일 › 수신** 열 아래의 **신뢰 표시**에서 **추가**를 엽니다.
2. **범위**(주소 하나 또는 도메인 전체)와 주소를 적고 **추가**를 누릅니다.

도메인 전체를 `seen`으로 표시하면 그 도메인의 누구든 해당됩니다. `gmail.com` 같은 공유 메일 도메인에는 쓰지 마세요.

## 받은 첨부 파일

에이전트는 `read_email`로 첨부 목록을 보고, 텍스트·PDF·이미지 첨부는 `read_attachment`로 바로 읽습니다. 그 밖의 파일은 `get_attachment_url`로 잠깐 쓸 수 있는 내려받기 링크를 받습니다. 첨부 내용도 외부 데이터로 다룹니다. 자세한 내용은 [받은 메일 API](/api/inbound#attachment-content)에 있습니다.
