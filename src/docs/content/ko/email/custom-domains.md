`agents.example.com`처럼 회사 도메인 아래 에이전트만 쓰는 서브도메인을 연결하면, 에이전트가 `scout@agents.example.com` 같은 주소로 메일을 주고받습니다. 정책·한도·승인 규칙은 `@atmark.ai` 주소와 똑같이 걸립니다.

## 시작하기 전에

- 지금은 베타로, 초대한 조직에만 열려 있습니다. 콘솔 **설정**에 **도메인** 메뉴가 없으면 아직 열리지 않은 조직입니다.
- 도메인을 추가하거나 제거하려면 역할이 소유자나 관리자여야 합니다. 멤버는 보기만 합니다.
- 도메인의 DNS 레코드를 고칠 수 있어야 합니다. DNS 제공자의 관리 화면을 미리 열어 두세요.
- 연결할 수 있는 도메인 수는 요금제가 정합니다. Beta·Pro는 1개, Team은 3개, Scale은 10개이고, 확인을 기다리는 도메인도 셉니다. 소유 확인을 기다리는 도메인은 한 번에 2개까지입니다.

## 어떤 도메인을 쓰나요 {#which-domain}

에이전트만 쓰는 **새 서브도메인**을 씁니다. 사람의 메일과 섞이지 않게 하려는 것입니다.

| 쓸 수 없는 도메인 | 이유 |
|---|---|
| 최상위 도메인(`example.com`) | 사람이 받는 메일이 있을 수 있습니다. `agents.example.com` 같은 서브도메인을 쓰세요. |
| 이미 다른 메일 서버가 있는 서브도메인 | 사람이 쓰는 메일을 가로채지 않으려고 연결하지 않습니다. |
| 공용 메일 서비스의 도메인 | 내 회사 도메인이 아닙니다. |
| `atmark.ai` 아래 도메인 | `@atmark.ai` 주소는 에이전트를 만들 때 따로 생깁니다. |
| 국제화 도메인(`xn--`) · 100자가 넘는 도메인 | 아직 받지 않습니다. |

## 도메인 연결하기 {#connect}

:::steps
### 도메인 추가
콘솔 **설정**에서 **도메인**을 열고 **도메인 추가**를 누릅니다. 서브도메인을 적고 **추가**를 누르면 그 도메인 화면이 열리고, 넣을 DNS 레코드가 나옵니다.

### 소유 확인 레코드 넣기
첫 카드 **소유 확인**의 TXT 레코드를 DNS 제공자에 넣습니다. 이 레코드는 최상위 도메인에 두는 `_atmark-challenge` 레코드입니다. 확인이 끝난 뒤에도 지우지 마세요.

### 메일 레코드 넣기
**메일 받기 · 반송 주소** 카드의 MX 레코드 둘과 TXT 레코드 하나를 넣습니다. 받는 메일과 반송이 이 레코드를 따라 Atmark로 옵니다. 소유 확인을 기다리는 동안 미리 넣어 두어도 됩니다.

### 서명 레코드 넣기
소유가 확인되면 **서명(DKIM)** 카드에 CNAME 레코드 3개가 나타납니다. 그대로 넣습니다.

### 확인 기다리기
Atmark가 저절로 확인합니다. 소유 확인을 기다리는 동안은 30분마다, 그 뒤로는 6시간마다 봅니다. 레코드를 넣은 직후 바로 보려면 **지금 확인**을 누릅니다(같은 도메인은 60초에 한 번).
:::

:::tip 이름 칸에는 앞부분만
DNS 제공자가 도메인 이름을 자동으로 붙인다면, 이름 칸에는 각 레코드 아래 회색으로 적힌 **앞부분**만 넣습니다. 전체 이름을 넣으면 도메인이 두 번 붙어 확인되지 않습니다. 값은 화면의 복사 단추로 그대로 옮깁니다.
:::

추가한 뒤 72시간 안에 소유가 확인되지 않거나, 소유가 확인된 뒤 72시간 안에 서명이 확인되지 않으면 도메인은 저절로 지워집니다. 도메인 화면의 **남은 시간**에 나옵니다. 지워져도 레코드를 고친 뒤 다시 추가하면 됩니다.

DMARC 레코드는 선택입니다. 이 도메인 앞에 `_dmarc.`을 붙인 이름으로 TXT 레코드 `v=DMARC1; p=none`을 두면, 받는 쪽이 이 도메인의 메일 정책을 알 수 있습니다. 최상위 도메인에 DMARC가 이미 있으면 그 정책이 이 서브도메인에도 적용됩니다.

## 상태 {#status}

| 상태 | 뜻 |
|---|---|
| **확인 대기** | 소유 확인 TXT 레코드를 기다립니다. |
| **확인 중** | 소유는 확인됐고, 서명·메일 레코드를 확인하고 있습니다. |
| **사용 중** | 이 도메인으로 주소를 만들고 메일을 주고받을 수 있습니다. 모든 레코드가 확인되면 **수신 · 발신 준비됨**이 함께 보입니다. |
| **정지됨** | 보내기가 멈췄습니다. 사유와 할 일은 [정지](#suspended)를 보세요. |
| **제거됨** | 더 이상 메일을 주고받지 않습니다. |

## 확인되지 않을 때 {#pending-reasons}

- **이 서브도메인에는 이미 다른 메일 서버가 있습니다** — 그 서브도메인의 MX 레코드가 다른 메일 서버를 가리킵니다. 에이전트만 쓸 새 서브도메인을 추가하거나, MX 레코드를 화면의 값으로 바꿉니다.
- **이 도메인은 아직 확인할 수 없습니다** — 최상위 도메인에 이전에 넣었던 다른 `_atmark-challenge` TXT 레코드가 남아 있습니다. 화면에 보이는 것 말고 다른 `_atmark-challenge` 레코드를 지운 뒤 **지금 확인**을 누릅니다. 그래도 안 되면 [지원팀](/help/contact)에 문의하세요.

## 이 도메인으로 주소 만들기 {#addresses}

- **에이전트 추가** — **에이전트 추가** 창의 **주소** 칸 끝(도메인 고르기)에서 이 도메인을 고르면, 그 주소가 에이전트의 대표 주소가 됩니다. 이 에이전트는 `@atmark.ai` 주소를 보이지도 쓰지도 않습니다. [에이전트 만들기](/agents/create)
- **있는 에이전트** — 에이전트 **주소** 화면에서 **별칭 추가**를 누르고 도메인을 고릅니다. 이 도메인의 별칭도 요금제의 별칭 수에 들어갑니다. [별칭 주소](/email/aliases)
- 내 도메인 주소가 대표인 에이전트에도 `@atmark.ai` 별칭을 달 수 있습니다. 꺼진 `@atmark.ai` 대표 주소(앵커)와는 다른, 새로 만든 별칭입니다.
- **대표 주소 바꾸기** — **주소** 화면에서 이 도메인 별칭 행의 ⋯ 메뉴에서 **대표로 고르기**를 누릅니다. 대표 주소는 에이전트가 보낼 때 기본으로 쓰고, 패스포트와 공개 조회에 나오는 주소입니다. 하루에 5번까지 바꿀 수 있습니다.

새 도메인은 하루에 보낼 수 있는 양이 작게 시작해 며칠에 걸쳐 늘어납니다. 그동안은 많이 보내지 못할 수 있습니다.

## @atmark.ai 주소는 어떻게 되나요 {#atmark-address}

내 도메인 주소를 대표로 고르면 그 에이전트의 `@atmark.ai` 주소는 **꺼집니다**. 콘솔·패스포트·공개 조회에 나오지 않고, 그 주소로 오는 메일은 거부되며, 그 주소로 보낼 수도 없습니다.

필요하면 에이전트 **주소** 화면의 **@atmark.ai 주소 켜기**로 언제든 다시 대표로 돌릴 수 있습니다. 내 도메인을 대표로 골라 만든 에이전트라면 이때 처음 보이는 주소가 `ax--`로 시작하는 무작위 이름입니다. 이 이름은 바꿀 수 없습니다.

## 정지 {#suspended}

| 사유 | 무슨 일인가요 | 할 일 |
|---|---|---|
| **소유 확인 실패** | 소유 확인 TXT 레코드가 사라졌습니다. 보내지도 받지도 않습니다. | 레코드를 화면의 값 그대로 다시 넣으면 저절로 복구됩니다. 14일 안에 복구되지 않으면 도메인이 제거되고 그 도메인의 주소도 폐기됩니다. |
| **서명 확인 실패** | 서명(DKIM) 레코드를 확인할 수 없습니다. 보내지도 받지도 않습니다. | CNAME 레코드 3개가 값 그대로 있는지 봅니다. 고치면 저절로 복구됩니다. |
| **발송 평판** | 반송이나 스팸 신고가 많아 보내기를 멈췄습니다. 받는 메일은 계속 받습니다. | [지원팀](/help/contact)에 문의하세요. |
| **운영자 정지** | Atmark 운영자가 보내기를 멈췄습니다. 받는 메일은 계속 받습니다. | [지원팀](/help/contact)에 문의하세요. |
| **요금제 한도** | 요금제를 내려 도메인 수가 한도를 넘었습니다. 받는 메일은 계속 받습니다. | 요금제를 올리거나 다른 도메인을 제거하면 저절로 다시 열립니다. |

정지되거나 제거될 때, 제거 3일 전, 도메인 등록 만료가 다가올 때 조직의 소유자와 관리자에게 알림 메일이 갑니다.

## 도메인 제거하기 {#remove}

도메인 화면 맨 아래 **도메인 제거**의 **제거**를 누르고 확인합니다. 제거한 도메인으로는 더 이상 메일을 주고받지 않습니다. DNS 레코드는 DNS 제공자에서 직접 지우세요.

- 이 도메인의 주소는 **기본으로 남겨 둡니다**. 같은 도메인을 다시 연결하면 그대로 돌아옵니다. 확인 창에서 **함께 폐기**를 고르면 주소도 지금 폐기합니다.
- 이 도메인 주소를 대표로 쓰던 에이전트는 **대표 주소가 없는** 상태가 됩니다. 저절로 `@atmark.ai` 주소로 옮기지 않습니다. 다른 별칭(`@atmark.ai` 별칭이나 다른 도메인의 별칭)이 있으면 그 별칭으로는 계속 받고, 보낼 때 그 별칭을 `from`에 적으면 보낼 수 있습니다. 별칭이 하나도 없으면 메일을 보내지도 받지도 않습니다.

:::danger 대표 주소를 이 도메인에 둔 에이전트는 대표 주소를 잃습니다
확인 창에 그런 에이전트 수가 나옵니다. 도메인을 다시 연결하거나, 에이전트 **주소** 화면에서 **@atmark.ai 주소 켜기**를 누르기 전까지 그 에이전트에는 기본으로 보내는 주소가 없습니다. 별칭이 없는 에이전트는 메일을 주고받지 못합니다.
:::

## 조직 API로 관리하기 {#org-api}

권한 `domains:manage`가 있는 [조직 API 키](/team/org-api-keys)로 같은 일을 할 수 있습니다.

| 메서드 | 경로 | 하는 일 |
|---|---|---|
| `GET` | `/domains` | 목록과 요금제 한도 |
| `POST` | `/domains` | 추가. 본문 `{"domain": "agents.example.com"}` |
| `GET` | `/domains/{domainId}` | 한 도메인과 넣을 레코드 |
| `POST` | `/domains/{domainId}/check` | 지금 확인(202) |
| `DELETE` | `/domains/{domainId}` | 제거. 본문 `{"releaseAddresses": true}`이면 주소도 폐기 |

에이전트를 만들 때 `POST /agents`의 본문에 `"domain": "agents.example.com"`을 더하면 그 도메인 주소가 대표 주소가 됩니다.

## 오류 코드 {#errors}

| 코드 | 뜻 |
|---|---|
| `registrable_apex` | 최상위 도메인입니다. 서브도메인을 쓰세요. |
| `shared_mailbox_domain` · `platform_domain` · `idn_label` · `too_long` · `invalid_label` | 쓸 수 없는 도메인입니다(위 표). |
| `domain_exists` | 이미 추가한 도메인입니다. |
| `plan_custom_domains_exceeded` | 요금제의 도메인 한도에 닿았습니다(확인 중 포함). |
| `custom_domains_pending_exceeded` | 소유 확인을 기다리는 도메인이 이미 2개입니다. |
| `domain_add_rate_limited` | 오늘은 도메인을 더 추가할 수 없습니다. |
| `domain_check_rate_limited` | 지금 확인을 너무 자주 눌렀습니다. 잠시 뒤 다시 누르세요. |
| `domain_not_verified` | 확인이 끝난 도메인만 주소에 쓸 수 있습니다. |
| `address_is_primary` | 대표 주소인 별칭은 삭제할 수 없습니다. 먼저 다른 주소를 대표로 고르세요. |
| `primary_change_rate_limited` | 대표 주소는 하루에 5번까지 바꿀 수 있습니다. |
| `feature_not_enabled` | 이 조직에는 아직 열리지 않았습니다. |
