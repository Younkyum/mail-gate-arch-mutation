## 시작하기 전에

- 역할이 소유자나 관리자여야 합니다.

## 발신 모드 {#modes}

| 모드 | 동작 |
|---|---|
| 전체 | 누구에게나 보냅니다. 한도·수신 거부 목록·내용 검사·위험 보류는 그대로입니다. **새 에이전트의 기본값**입니다. |
| 허용 목록 | 허용 목록에 있는 주소·도메인에만 보냅니다. 나머지는 막힙니다. 보낼 상대가 정해지면 **권장**합니다. |
| 차단 목록 | 차단 목록에 있는 상대만 막고 나머지에는 보냅니다. |
| 모두 막기 | 아무에게도 보내지 않습니다. 모든 발송이 거부됩니다. |

목록 밖 상대에게 보내는 메일은 승인 요청 없이 바로 막힙니다. 받는 사람이 여럿이면 한 명이라도 막히는 순간 메일 전체가 나가지 않습니다.

소유자나 관리자가 콘솔에서 만든 에이전트는 **전체**로 시작합니다(2026년 10월 13일부터). 조직 API 키나 [자가 등록](/api/agents)으로 만든 에이전트는 빈 허용 목록으로 시작하고, 이미 있는 에이전트는 모드가 그대로입니다.

:::steps
### 이메일 화면 열기
에이전트 화면에서 **이메일**을 누릅니다. 화면이 좁으면 위의 **발신** 탭을 고릅니다.

### 모드 고르기
**발신** 열에서 모드를 누릅니다. 지금 쓰는 모드에는 **현재** 표시가 붙어 있습니다.

### 저장하기
열 아래의 **저장**을 누릅니다. 저장할 때마다 새 정책 버전이 생기고 바로 적용됩니다.
:::

![이메일 화면의 발신 열](shot:agent-email)

:::warning "전체"로 둘 때
"전체"는 에이전트가 누구에게나 메일을 보낼 수 있다는 뜻입니다. 토큰이 새거나 에이전트가 메일 속 지시에 속으면 모르는 사람에게도 나갑니다. 위험 보류가 의심스러운 메일을 읽은 직후 새 상대에게 보내는 메일을 붙잡지만, 모든 경우를 보지는 못합니다. 보낼 상대가 정해져 있다면 허용 목록에 넣고 허용 목록 모드로 바꾸세요.
:::

## 발송 결과

에이전트는 보낼 때마다 결과 하나를 받습니다.

| 결과 | 뜻 | 에이전트가 할 일 |
|---|---|---|
| `sent` | 나갔습니다. | 없음 |
| `denied` | 정책이나 한도에 막혔습니다. 사유 코드가 같이 옵니다. | 다시 보내지 않고 소유자에게 알립니다. |
| `pending_approval` | 사람이 승인해야 나갑니다. 의심스러운 메일 뒤의 위험 보류, 발신 승인 "항상", 예전 발신 모드에서 생깁니다. | 다시 보내지 않고 기다립니다. [승인](/email/approvals) |

자주 보는 거부 사유는 [메일이 안 나갈 때](/help/troubleshooting-sending)에 모았습니다.

## 에이전트가 할 수 없는 것

에이전트는 `get_my_policy`로 자기 정책을 읽을 수만 있습니다. 모드와 목록은 콘솔에서 소유자나 관리자만 바꿉니다. 에이전트는 `request_policy_change`로 [변경을 요청](/email/allow-block-lists#requests)할 수 있지만, 소유자나 관리자가 승인하기 전에는 아무것도 바뀌지 않습니다.
