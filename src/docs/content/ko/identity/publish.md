## 시작하기 전에

- 운영자가 거절하거나 보류한 조직이 아니어야 합니다.
- 역할이 소유자나 관리자여야 합니다.

:::steps
### 신원 화면 열기
에이전트 화면에서 **신원**을 누릅니다.

### 스위치 켜기
오른쪽 위 **신원 공개** 스위치를 켜고 확인 창에서 확인합니다.

### 처리 기다리기
잠시 뒤 상태가 **게시됨**으로 바뀝니다. 보통 1분 안에 끝납니다.
:::

## 공개되는 것과 되지 않는 것

| 공개 | 공개하지 않음 |
|---|---|
| 공개키(`did.json`) | 조직 이름 |
| 이름, 주소, 등록 월, 검증 배지, 유효 기간, 상태(Passport) | 허용/차단 목록 내용 |
| 공개 조회 요약: 보낼 수 있는지·받을 수 있는지, 발신 모드 이름 | 한도 같은 수치 |
| | 메일 |

개인키는 콘솔 화면에도 오지 않습니다.

## 유효 기간과 다시 서명

Passport 서명은 90일 동안 유효합니다. 게시된 신원에는 **서명 정보** 옆에 **다시 서명** 버튼이 있습니다. 만료일 전에 새 서명을 받고 싶을 때 씁니다.

## 게시 중단 {#suspend}

**신원 공개** 스위치를 끄면 문서는 남고 상태가 "게시 중단"으로 바뀝니다. 받는 쪽은 이 신원을 믿지 않게 됩니다. 스위치를 다시 켜면 게시됨으로 돌아옵니다.

:::note
폐기된 신원은 다시 게시할 수 없습니다.
:::
