Atmark는 AI 에이전트에게 검증 가능한 신원과 이메일 주소를 발급하는 서비스입니다. 에이전트는 사람 계정을 빌리지 않고 자기 이름으로 메일을 주고받습니다.

## 이럴 때 맞습니다

- 에이전트가 사람 계정을 빌리지 않고 자기 주소로 메일을 주고받아야 할 때
- 에이전트가 사이트에 가입하거나 로그인하면서 인증 코드를 받아야 할 때
- 에이전트가 누구에게 보낼지 사람이 정하고, 무엇이 나갔고 막혔는지 기록으로 보고 싶을 때
- 메일을 받는 쪽이 보낸 주소가 정말 에이전트의 것인지 확인할 수 있어야 할 때

## 이럴 때는 맞지 않습니다

- 자기 회사 도메인(`@yourcompany.com`)의 주소가 필요할 때. 지금은 `@atmark.ai` 주소만 드립니다.
- 주소를 나중에 바꿔야 할 때. 주소는 바꿀 수 없습니다. 에이전트를 지우면 주소도 함께 삭제됩니다.
- 사람이 콘솔에서 받은 메일을 읽을 메일함이 필요할 때. 콘솔은 받은 메일의 기록만 보여 주고 본문은 열지 않습니다.
- 콜드 아웃리치, 대량·마케팅 발송, 받는 사람이 기대하지 않은 메일을 보내려 할 때. [Atmark로 하면 안 되는 일](/get-started/not-for)

## 에이전트가 받는 것

| 항목 | 내용 |
|---|---|
| 이메일 주소 | `이름@atmark.ai` 형식. 만든 뒤에는 바꿀 수 없습니다. |
| DID | 에이전트를 가리키는 공개 식별자. 에이전트마다 따로 생기고, `did:web` 방식이라 누구나 웹에서 조회합니다. |
| Passport | 이 에이전트의 이름·주소·상태를 적고 에이전트 키로 서명한 증명서. 받는 쪽이 진짜인지 확인할 때 씁니다. 90일 동안 유효합니다. |
| 신원 카드 | 콘솔에서 이름·주소·DID·상태를 한 장에 모아 봅니다. |
| 토큰 | 에이전트가 MCP나 REST API로 연결할 때 쓰는 비밀 |

신원을 게시하면 메일을 받은 쪽이 공개 문서만으로 이 주소가 Atmark가 발급한 에이전트의 것인지, 지금도 유효한지 직접 확인합니다. [에이전트 신원 확인하기](/identity/verify)

## 소유자가 정하는 것

- **누구에게 보낼지.** 새 에이전트는 발신 모드 "전체"로 시작합니다. 보낼 상대가 정해지면 허용 목록으로 좁히고, 새 상대가 필요하면 에이전트가 소유자에게 추가를 요청할 수 있습니다.
- **누구의 메일을 볼지.** 막힌 메일은 반송하지 않고 보류합니다. 에이전트에게는 보이지 않습니다.
- **언제 멈출지.** 긴급 정지 한 번으로 에이전트 하나나 조직 전체의 발신을 멈춥니다.

에이전트는 자기 정책을 읽을 수만 있고 바꿀 수는 없습니다. 모든 발송은 관문 하나를 지나고, 관문은 수신 거부 목록과 발송 한도, 소유자 정책을 모두 확인합니다.

## 비용이 드나요 {#cost}

가입은 대기자 명단의 초대로 이루어지고, 초대로 가입하면 바로 Free 요금제로 시작합니다. Beta 요금제는 운영자가 초대한 조직만 무료로 씁니다. 베타 기간에는 결제가 열리지 않습니다. 유료 요금제의 월 가격은 [가격 페이지](https://atmark.ai/kr/pricing)에 있습니다.
