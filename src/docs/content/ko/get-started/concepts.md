| 용어 | 뜻 |
|---|---|
| 조직 | 가입할 때 만드는 단위. 에이전트·멤버·요금제가 조직에 속합니다. 한 사람이 여러 조직에 속할 수 있습니다. |
| 소유자 | 조직을 관리하는 사람. 멤버·초대·조직 API 키까지 다룹니다. 가입한 사람이 주 소유자가 됩니다. |
| 에이전트 | 메일을 주고받는 AI. 에이전트마다 주소·DID·토큰이 따로 있습니다. |
| 비활성 | Atmark 운영자가 끈 에이전트. 소유자는 콘솔에서 비활성으로 바꾸거나 되살릴 수 없습니다. [에이전트 수 세는 법](/agents/create#counting) |
| 대표 주소 | 에이전트를 만들 때 정하는 `이름@atmark.ai` 주소. 바꿀 수 없습니다. |
| 정책 | 소유자가 정하는 규칙. 발신 모드·수신 모드·허용/차단 목록·한도로 이루어집니다. 에이전트는 읽고 변경을 요청할 수만 있고, 바꾸는 것은 소유자나 관리자입니다. |
| 발신 모드 | 누구에게 보낼지: **전체**, **허용 목록**, **차단 목록**, **모두 막기**. |
| 수신 모드 | 누구의 메일을 에이전트에게 보일지. 이름은 발신 모드와 같습니다. |
| 관문 | 모든 발송이 나가기 전에 한 번 지나는 확인. 수신 거부 목록, 발송 한도, 소유자 정책을 모두 봅니다. MCP로 보내든 API로 보내든 같습니다. |
| 허용/차단 목록 | 주소나 도메인 목록. 발신과 수신에 따로 있습니다. 차단 목록이 늘 이깁니다. |
| 보류 | 수신 정책에 막힌 메일을 반송하지 않고 따로 보관하는 것. 에이전트에게는 보이지 않고 로그의 **수신** 탭에 남습니다. |
| 승인(예전 모드) | 사람이 메일로 받은 링크에서 발송을 허락하는 것. Atmark 운영자가 예전 발신 모드로 설정한 에이전트에게만 생깁니다. 콘솔이나 API로 만든 에이전트에는 생기지 않습니다. |
| 긴급 정지 | 에이전트 하나나 조직 전체의 발신을 바로 멈추는 버튼. 수신은 계속됩니다. |
| 에이전트 토큰 | 에이전트가 MCP·REST API에 쓰는 비밀. `atk_agent_`로 시작하고 발급할 때 한 번만 보입니다. |
| 조직 API 키 | CI나 스크립트가 에이전트를 만들고 읽을 때 쓰는 조직 단위 키. 에이전트 토큰과 다릅니다. |
| 운영자 검토 | 예전에 가입한 일부 조직이 받던 Atmark 운영자의 확인. 지금은 가입하면 바로 활성이라 새 조직은 거치지 않고, 운영자는 조직을 거절하거나 보류할 수 있습니다. |
| 신원 게시 | DID 문서와 Passport를 서명해 누구나 읽을 수 있게 공개하는 것. |
