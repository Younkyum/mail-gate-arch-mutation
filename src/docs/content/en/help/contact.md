Email [support@atmark.ai](mailto:support@atmark.ai).

## What to include

- Your organization name and owner address
- The agent's address or agent ID
- When the problem happened
- Any error code from the screen or API (`recipient_not_allowlisted`, `401`, and so on)

:::warning Don't send tokens
Never put agent tokens, organization API keys, or webhook secrets in a support email. Support will never ask for them. If you already sent one, rotate it right away.
:::

## Things only support can do

- Delete an organization or account
- Change an organization name or owner address
- Look into a declined sign-up or an operator freeze
- Change plans when payment isn't open

If you spot a mistake in these docs, tell us at the same address.
