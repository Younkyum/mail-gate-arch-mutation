Choose **Settings** in the sidebar to open the settings menu. Only the item you pick is shown on the right. On a narrow screen, the menu becomes tabs across the top.

| Group | Item | What it's for |
|---|---|---|
| Organization | General | Organization name, id, owner, review status, and your role |
| | Members & invites | Members, roles, and invites. See [Members and roles](/team/members-and-roles). |
| | API keys | Organization API keys. See [Organization API keys](/team/org-api-keys). |
| | Plan | Plan and usage, upgrading. See [Change your plan](/plans/change-plan). |
| Operations | Emergency stop | Stop sending for the whole organization. See [Emergency stop](/email/emergency-stop#org). |
| Personal | Display | Theme (System, Light, Dark) and language. Saved in this browser. |
| | Email | System email language (English, 한국어). Login codes, approval requests and notices come in this language. |
| | Sessions | The address you're logged in as, and logging out |

## General

The name and owner address are set at sign-up and can't be changed here. If you need to change them, [contact support](/help/contact).

## Sessions {#session}

- You log in with the 6-digit code sent by email. It works once, for 15 minutes, in the browser that requested it. If you read the email on your phone, type the code into that browser.
- Sessions last 12 hours.
- **Log out everywhere** ends all of your console sessions: every organization, other browsers and devices, and this browser too. Use it if you think a session leaked.

## Deleting your account

You can't delete an account or organization from the console. [Contact support](/help/contact).
