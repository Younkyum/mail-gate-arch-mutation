- 대상 저장소: `atmark-src` (git, 커밋 326개, 2026-09-22 f1ecc217 ~ 2026-10-15 dcf9f7ef)

## 0. 정의와 포함 기준

**공허한 검증**: 테스트나 검사(arch 단언, 변이 판정, CI 게이트, 수용 기준 판정기)가 초록(통과)인데, 그 검사가 지킨다고 주장하는 성질은 실제로 지키지 못하던 상태. 지키던 방어 코드를 지우거나 우회해도 초록이 그대로였다.

포함 조건(엄격 적용):
1. 저장소 안에 구체 증거가 있어야 한다. 커밋 메시지나 코드 주석에 "지워도 초록", "통과했다", "잠들어 있었다", "공허했다"처럼 검사가 무반응이었다는 진술이 있어야 한다.
2. 대상은 **검증 장치**의 결함이다. 제품 방어 코드 자체의 결함(예: DB CHECK 가 NULL 을 통과시킴)은 본 표에서 빼고 부록 A에 따로 모았다.
3. 증거가 간접적이면 "확실도: 중/하"로 표시했다.

발견 경로는 행위자와 기법 두 축으로 분류했다.
- **행위자**: 독립 검증 에이전트(verifier, 적대적 검증, 재검증) / 코드 리뷰어 / 작성자 자신 / CI 실행 / 미상
- **기법**: (R) 되돌리기·무력화·위반 심기 실험 / (B) 우회 입력 구성 / (S) 정적 읽기 / (X) 실행 관찰
